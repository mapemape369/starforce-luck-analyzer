# starforce-luck-analyzer
Star Force Luck Tracker
스타포스 확률을 기록하는 프로그램입니다.

사용법
위 항목에서 기본적으로 강화 단계를 고를 수 있으며, 예를 들어 21성에서 시작하고 싶다면 [21]을 고르고 [강화 단계 변경]을 누르면 됩니다.
성공 버튼을 누르면 자동적으로 스타포스 단계가 올라가며, 파괴시 gms 스타포스 공식에 따라 특정 단계로 하락됩니다.(2026.02.16 기준) 
아래쪽에는 각 단계별로 총 시도, 성공, 실패, 파괴가 기록되며 '전체적인' 스타포스의 운도 표기 됩니다. (%가 높을수록 운이 안좋음)
단계별 통계 보기를 통해 각 단계별 표기 확률과 실제로 겪은 확률을 비교해서 볼 수 있으며, '단계별' 스타포스 운도 확인 가능합니다. (어느 구간에서 운이 좋고, 어느 구간에서 운이 안좋은지 확인가능)
데이터는 전체 초기화 기능만 지원하기 때문에 기록할때는 신중하게 해야합니다.
